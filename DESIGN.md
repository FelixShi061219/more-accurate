# Transparent indicator

Surface mode: Operate. Preserve the established capsule/water-ball, pale silver gray #E2E5E9, smooth black contour and subtle downward feathered shadow. Exterior canvas pixels remain transparent; no native chrome or taskbar entry. The user's handwritten typography, pastel gradients and explicit sector geometry override generic UI style defaults.

Bar canvas390×98, main capsule(12,28),366×42. Percentage sits on the right, vertically centered; task name fills the left when multiple tasks exist. No visible understanding label and no model/network panels. Actual task strip200×10 below the main shape; only running execution reveals it through a damped spring.

Shared wheel uses a 300×300 drawing coordinate system rendered into a 150×150 topmost window (50% scale). Equal angular spans360/n for1–4 selected tasks, using contiguous true pie-chart wedges that radiate from the center. Wedges touch at their radial boundaries; only their antialiased outline separates them, with a radius9 central hole retained. Each sector has independently clipped water height across its vertical bounds, provider, task number and percentage/None. All text dark #13171B and handwritten; no text shadow. Task arc radius117, thickness6, rounded ends, separated from sector perimeter. Only the task's sector sweep represents100%; no uncompleted track. Unknown totals move a short arc inside the same sweep. Completion/interruption removes it.

Latin handwriting: Comic Sans MS, Segoe Print, Ink Free; Chinese: 华文行楷/STXingkai, 楷体/KaiTi, 华文楷体. System fallback when absent; never bundle OS fonts. Pastels: below25 dusty pink;25–50 apricot;50–75 cream;75–90 lavender;90–100 mint #7ACB9F/#B0E7BC/#8DDCC6. Execution arc muted eucalyptus. Gray unfilled water area is distinct from an absent execution-track background.

Double-click combines/expands selected tasks. Spring appearance and score interpolation, slow waves, drag-driven damped tilt, three bouncing dots only after new reports. Full canvas and shadow constrained to monitor work areas including negative coordinates and display changes. Right-click: task selection, desktop linking, copy instruction, Language, mandatory topmost status, opt-in login startup/position memory, exit. Every startup clears the previous selection and shows an unnamed None indicator. The first fresh report or new connection may populate it automatically; historical tasks require explicit selection. Choosing multiple tasks is temporary for that run. Connector text rows size to the actual font metrics; selector and connector dialogs suspend indicator surfaces until closed.

App icon uses the user's supplied chat/check drawing. Reproducible sources in app/icons and tools/build-icon.py. Controlled fixture images used for QA contain illustrative values only.
