# Changelog

## 1.2.0 — 2026-10-26

- Startup keeps an unnamed None bar instead of selecting a historical Codex task. A fresh report/new connection may populate the first task; historical tasks remain available for manual selection.
- Desktop connector labels use automatic font-aware row heights; AI suggestions follow the selected window and remain editable. Connector/selector dialogs temporarily hide indicators so dropdowns and buttons remain accessible.
- English and Chinese README include actual connector screenshots plus controlled startup, task/ball and five-color understanding examples.
- Rename the installer entry point to Install.cmd. Grouped ball uses a reduced 150px canvas; selected bars move together and language applies across the UI.
- Independent Codex task IDs; manual selection of up to four tasks without eviction.
- Chrome/Edge native messaging extension for ChatGPT, DeepSeek, Claude and Gemini; opt-in scoring instructions and marker-only transfer.
- Per-chat desktop linking with selected-window accessibility readers, unique markers, bounded subprocesses and explicit retry.
- Shared1/2/3/4-sector ball with contiguous wedges, independent water/labels and separated per-sector execution arcs; double-click restores bars.
- Handwriting in indicator content and context menus, system fonts in connector/selector dialogs, spring appearance, update dots, screen bounds and optional startup/position memory.
- Stable browser conversation identities, request ordering, stale-marker filtering and fresh-start None.
- Isolated protocol, controlled-page, selector/sector and accessibility-fixture tests. Live vendor/client compatibility remains unverified.
- Preserve the lean Skill and duplicate-sync reduction. The main multi-task UI no longer starts legacy telemetry or installs its configuration.

## 1.1.0

- Reduce Skill overhead: retain task scoring records, coalesce unchanged syncs, report meaningful milestones without heartbeats, and suspend retries after connection failure. All features retained; latency gains are not benchmarked.

- Sync understanding at request start and before clarification/input tools; do not wait until a final response or inherit the previous task's 100%.

- Requirement understanding is the only score; old reliability/mode inputs remain accepted for upgrade compatibility.
- Startup None; pale gray main shape; label removed; handwritten percentages. Actual task step progress uses a thicker strip or a separated ring with transparent unfinished sector. Hidden outside task execution.
- Removed model/network companion panels; metadata remains available in hover diagnostics. Added update_task_progress MCP and Skill milestone reporting.
- Immediate Chinese/English UI selection with persistence.
- Desktop shortcut named More Accurate and application icon based on the user's drawing.
- Skill requires explicit unknowns, evidence-based inference and honest execution reports.
- Windows PowerShell 5.1-compatible installation, isolated tests and GitHub CI/documentation.
